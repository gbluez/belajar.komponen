Pelatihan Pra SKKNI Teknisi HP

Dokumen ini dirancang untuk membantu teknisi HP lulus uji kompetensi SKKNI, menguasai troubleshooting real, dan memiliki SOP kerja profesional.

🧠 1. Kisi-Kisi Ujian (Ringkas & Tepat Sasaran)

A. Dasar Elektronika

  • Hukum Ohm (V = I x R)
  • Fungsi komponen:
    • Resistor → pembatas arus
    • Kapasitor → penyimpan sementara
    • Dioda → penyearah
    • IC → pengolah sinyal

B. Alat Kerja

  • Multimeter → ukur tegangan / resistansi
  • Power Supply → analisa arus
  • Solder & Blower → bongkar pasang komponen

C. Hardware HP

  • Jalur Vbat
  • IC Power (PMIC)
  • CPU, eMMC/UFS

D. Software

  • Flashing
  • FRP
  • Bootloop

🔧 3. Studi Kasus Real (WAJIB KUASAI)

CASE 1: Mati Total (No Power)

Gejala: Tidak ada respon, Tidak terdeteksi PC

Analisa:

  • Cek tegangan baterai
  • Gunakan PSU:
    • Jika arus 0.00 → jalur putus / IC mati
    • Jika arus naik turun → CPU kerja

Kemungkinan: PMIC rusak atau Jalur Vbat putus.

CASE 2: Konslet / Short

Gejala: PSU langsung tinggi (0.5A ke atas), Panas di board

Langkah:

  1. Mode diode
  2. Cek jalur Vbat
  3. Inject tegangan

Target: Temukan komponen panas.

CASE 3: Tidak Charging

Gejala: Colok charger tidak respon

Analisa:

  • Cek konektor
  • Cek IC charging
  • Cek jalur USB
CASE 4: Bootloop

Solusi:

  1. Flash firmware
  2. Jika gagal → eMMC bermasalah

🧪 4. Simulasi Ujian Praktik

Tugas: Diberikan HP mati total.

Yang dinilai:

  • Cara pegang alat
  • Alur analisa
  • Keputusan teknis

Standar Jawaban:

  1. Cek visual
  2. Cek tegangan baterai
  3. PSU test
  4. Analisa arus
  5. Tentukan titik masalah

✅ 5. Checklist Teknisi Profesional

Sebelum Perbaikan

  • Catat kondisi awal
  • Tanya keluhan user
  • Cek fisik unit

Saat Perbaikan

  • Gunakan ESD
  • Tidak asal jumper
  • Ukur sebelum ganti

Setelah Perbaikan

  • Test fungsi
  • Bersihkan unit
  • Edukasi user

🚀 6. Tips Lulus SKKNI

  • Jangan hafal, pahami alur
  • Fokus ke arus & logika
  • Jangan tebak, selalu ukur
"Teknisi yang lulus bukan yang paling pintar, tapi yang paling sistematis.

Ukur → Analisa → Eksekusi"
